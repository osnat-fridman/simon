# סיימון

משחק זיכרון לטלפון: לוח עגול בארבעה צבעים מציג רצף אורות וצלילים שמתארך בכל שלב, וצריך לחזור עליו. 10 שלבים.

- **האתר:** https://osnat-fridman.github.io/simon/
- **הקוד:** https://github.com/osnat-fridman/simon

## פתיחה והתקנה בטלפון

- **פתיחה:** פותחים את הכתובת בדפדפן. אין צורך בהתקנה כדי לשחק.
- **iPhone (Safari):** כפתור השיתוף ← ״הוספה למסך הבית״ ← ״הוספה״.
- **Android (Chrome):** תפריט שלוש הנקודות ← ״התקנת אפליקציה״ (או ״הוספה למסך הבית״).
- האייקון ״סיימון״ נפתח במסך מלא, בלי שורת כתובת.
- **בלי אינטרנט:** עובד רק אחרי פתיחה ראשונה עם אינטרנט (הקבצים נשמרים במכשיר ברקע). פתיחה ראשונה בלי אינטרנט לא תעבוד.
- **צלילים:** אם אין צליל, בדקו שמצב שקט כבוי ושעוצמת המדיה פתוחה.

## עדכונים

כל שינוי שמאושר לענף `main` נבדק אוטומטית ב-GitHub, ורק אם כל הבדיקות עברו הוא מתפרסם לאתר (תוך כמה דקות). Pull Request רק נבדק ואינו מתפרסם.

מי שכבר פתח את המשחק ממשיך עם הגרסה הקודמת עד שהוא סוגר את כל הלשוניות של האתר (או את האפליקציה המותקנת) ופותח מחדש. כך עדכון לעולם לא קוטע משחק.

## חזרה לגרסה קודמת (Rollback)

1. ב-GitHub, ב-Commit שגרם לבעיה, מבצעים Revert (או `git revert <commit>` ו-`git push`).
2. ה-Push ל-`main` מפעיל את אותו תהליך בדיקה ופרסום, והגרסה הקודמת חוזרת לאתר.
3. מי שכבר פתח את הגרסה הבעייתית יקבל את הגרסה המתוקנת רק אחרי סגירה מלאה ופתיחה מחדש.

אם הבדיקות נכשלות, שום דבר לא מתפרסם והאתר הקיים נשאר כמו שהוא.

## מגבלות

- **התוצאה האחרונה נשמרת רק במכשיר ובדפדפן שבו שיחקו.** אין חשבונות ואין סנכרון בין מכשירים.
- בחלק מהמכשירים (בעיקר iPhone) האתר בדפדפן והאפליקציה המותקנת שומרים כל אחד תוצאה **נפרדת**.
- מחיקת נתוני האתר בדפדפן מוחקת את התוצאה ואת ההכנה לשימוש בלי אינטרנט.
- הדפדפן עשוי למחוק נתונים שמורים של אתר שלא נפתח זמן רב, בעיקר כשהמקום במכשיר מצומצם.
- שינוי כתובת האתר (שם ה-Repository או Domain) ינתק התקנות ותוצאות קיימות.

## פיתוח ובדיקות

```bash
npm ci
npm run dev          # http://localhost:5173/simon/
npm run typecheck
npm test             # Vitest
npm run test:e2e     # Playwright: Chromium, WebKit ו-PWA מול Build מקומי
npm run test:live    # Playwright מול האתר החי
```

בדיקת עדכון בין שתי גרסאות באתר החי: מריצים `SIMON_LIVE_UPDATE=1 npm run test:live`, ובזמן שהיא ממתינה מפרסמים גרסה חדשה ל-`main`.
